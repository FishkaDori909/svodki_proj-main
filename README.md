# Сводка 2-х час ГПН-Ямал — автоматическая сборка

Программа сама собирает «Сводку 2-х час ГПН-Ямал» из файла ПОНМ.

**Как это работает**

1. Вы кладёте файл ПОНМ (`.xlsb`, `.xlsm` или `.xlsx`) в папку `data\inbox` — или он приходит по почте.
2. Программа раз в минуту проверяет папку, находит новый или изменённый файл и собирает по нему сводку.
3. Готовая сводка появляется в папке `data\results`. Если включена отправка почты, она уходит письмом (вместе с PDF).

Всё остальное — журнал, удаление старых файлов, повторные проверки — программа делает сама.

---

## 1. Что понадобится

- Компьютер с Windows.
- Python 3.10 или новее — скачать на [python.org](https://www.python.org/downloads/). При установке обязательно отметьте галочку **Add Python to PATH**.
- *(необязательно)* LibreOffice — только если нужен PDF во вложении письма. Скачать на [libreoffice.org](https://www.libreoffice.org/download/).
- *(необязательно)* Данные почтового сервера — если нужна отправка или приём писем.

## 2. Установка и первый запуск

Откройте папку проекта, нажмите в пустом месте папки правой кнопкой мыши с зажатым `Shift` и выберите **«Открыть окно PowerShell здесь»** (или «Открыть в Терминале»). Дальше выполняйте команды по порядку.

**Шаг 1. Установите нужные библиотеки** (один раз)

```powershell
pip install -r requirements.txt
```

**Шаг 2. Создайте файл настроек** (один раз)

```powershell
copy config\config.example.toml config\config.toml
```

Откройте `config\config.toml` в Блокноте и при необходимости поправьте значения (подробности — в разделе 3). Для простой работы с папкой менять ничего не нужно.

**Шаг 3. Проверьте настройки**

```powershell
python -m svodka check
```

Должно появиться «Настройки в порядке». Если есть ошибка — в тексте написано, что исправить.

**Шаг 4. Запустите программу**

```powershell
python -m svodka watch
```

Программа работает, пока открыто окно PowerShell. Чтобы остановить её, нажмите `Ctrl+C`.

## 3. Настройка

Все настройки находятся в одном файле — **`config\config.toml`**. Каждая строка в нём подписана. После изменения остановите программу (`Ctrl+C`) и запустите снова.

### Главные параметры

| Параметр | Что означает | Значение по умолчанию |
|---|---|---|
| `inbox` | Папка, куда кладутся файлы ПОНМ | `data/inbox` |
| `results` | Папка с готовыми сводками | `data/results` |
| `interval_seconds` | Как часто проверять папку, секунд | `60` |
| `keep_days` | Через сколько дней удалять старые файлы (`0` — не удалять) | `30` |
| `timezone` | Часовой пояс, по которому определяется текущий день и время | `Asia/Yekaterinburg` |
| `max_file_mb` | Файлы больше этого размера не принимаются | `50` |

Пути в настройках можно писать от папки программы (`data/inbox`) или полностью (`C:/Сводки/входящие`). Пишите их с обычной косой чертой `/`.

### Приём файлов из почты

Включайте, если файлы ПОНМ приходят письмом, а почта хранится на этом компьютере в почтовой программе (например, Thunderbird) в формате mbox.

```toml
[mail_in]
enabled          = true
mbox_path        = 'C:\Users\Имя\AppData\Roaming\Thunderbird\Profiles\xxxx.default\Mail\Local Folders\Сводка'
restrict_senders = true
allowed_senders  = ["ivanov@company.ru", "@company.ru"]
```

- `mbox_path` — путь к файлу почтовой папки. Если пишете обратной косой чертой `\`, берите путь в **одинарные** кавычки, как в примере.
- `restrict_senders = true` — вложения принимаются только от отправителей из списка `allowed_senders`. `false` — проверка отключена, принимаются вложения от любых отправителей, а список можно не заполнять.
- `allowed_senders` — список тех, чьи файлы принимаются, обязателен при `restrict_senders = true`. Можно писать адрес целиком или весь домен (`@company.ru`). Письма от остальных игнорируются.

Если почта хранится не на этом компьютере — просто кладите файлы в `data\inbox` сами.

### БП и коэффициенты (вписываются руками)

Значения БП и «Коэффициент в расчёте» с датой хранятся в отдельном файле — **`config\manual_values.toml`**. Создайте его один раз из образца:

```powershell
copy config\manual_values.example.toml config\manual_values.toml
```

Каждая строка в файле подписана так же, как строка в столбце B сводки:

```toml
[bp]
"Добыча ПНГ - БП" = 1004021.656

[coefficients]
"Стабильный конденсат ПНГ (НТК-1)" = { "Коэффициент" = 0.67, "Дата" = "01.06.2026" }
```

- Меняйте только числа и даты, названия в кавычках не трогайте.
- Дробная часть — через точку (`0.67`), дата — в кавычках, вида `"01.06.2026"`.
- Значения попадают на все листы дней. После сохранения файла сводка пересоберётся сама.
- Ошибку в файле (опечатку в названии, число с запятой) покажет `python -m svodka check`.
- Если строку удалить, в сводке останется значение из образца.

### Отправка готовой сводки по почте

```toml
[mail_out]
enabled         = true
from            = "svodka@company.ru"
to              = ["boss@company.ru", "team@company.ru"]
reply_to_sender = false
attach_pdf      = true

[smtp]
server   = "mail.company.ru"
port     = 587
security = "starttls"
login    = "svodka@company.ru"
```

- `from` — от чьего имени уходит письмо, `to` — кому.
- `reply_to_sender = true` — копия уходит ещё и тому, кто прислал файл ПОНМ по почте.
- `attach_pdf = true` — к письму прикладывается PDF. Нужен LibreOffice. В PDF попадает только последний лист сводки (текущие сутки), диапазон `B1:P108`, уменьшенный до одной страницы.
- `max_attachment_mb` — если письмо получается больше этого размера, вложения не прикладываются, а в тексте письма сказано, где лежит файл.
- `verify_certificate = false` (в разделе `[smtp]`) — не проверять сертификат почтового сервера. Нужно, если в `server` указан IP-адрес, а не имя, и появляется ошибка `CERTIFICATE_VERIFY_FAILED`. Включайте только во внутренней сети.

**Пароль от почты лучше не писать в `config.toml`.** Сохраните его так (один раз), затем закройте окно PowerShell и откройте новое:

```powershell
setx SVODKA_SMTP_PASSWORD "ваш_пароль"
```

## 4. Ежедневная работа

**Положить файл вручную.** Скопируйте файл ПОНМ в папку `data\inbox`. Примерно через минуту готовая сводка появится в `data\results` под именем:

```
Сводка 2-х час ГПН-Ямал — <имя вашего файла>.xlsx
```

**Получить по почте.** Если включены приём и отправка — ничего делать не нужно: пришёл файл — ушла сводка.

**Обновили файл ПОНМ.** Положите новую версию в ту же папку — сводка пересоберётся.

**Посмотреть, что происходит.** Журнал работы — файл `logs\svodka.log`, его можно открыть в Блокноте. Последние записи — в конце файла.

**Собрать сводку один раз вручную** (не включая постоянную работу):

```powershell
python -m svodka build "data\inbox\Мой файл.xlsb"
```

**Один проход по папке и выход** (удобно запускать по расписанию):

```powershell
python -m svodka once
```

## 5. Если что-то не работает

| Что происходит | Что делать |
|---|---|
| Сводка не появляется | Проверьте, что файл лежит именно в `data\inbox` и имеет расширение `.xlsb`, `.xlsm` или `.xlsx`, и что программа запущена. Посмотрите журнал `logs\svodka.log`. |
| Файл исчез из `data\inbox` и оказался в `data\errors` | Файл не похож на ПОНМ, слишком большой или повреждён. Причина записана в журнале. |
| Письмо не уходит | В журнале найдите строку «письмо не отправлено» — рядом причина. Проверьте `server`, `port`, `login` и пароль. |
| Ошибка `CERTIFICATE_VERIFY_FAILED` | Сертификат почтового сервера не подходит к его адресу. Впишите в `server` имя сервера вместо IP или поставьте `verify_certificate = false`. |
| В журнале «Message size exceeds» | Почтовый сервер не принимает такие большие письма. Уменьшите `max_attachment_mb` или поставьте `attach_pdf = false`. |
| PDF не прикладывается | В журнале строка «не удалось сделать PDF». Проверьте, что установлен LibreOffice. Письмо в таком случае уходит без PDF. |
| Файлы из почты не принимаются | В журнале строка «не из списка разрешённых отправителей». Добавьте адрес в `allowed_senders` или отключите проверку: `restrict_senders = false`. |
| Сводки собираются заново из старых писем | Программа запоминает прочитанные письма в папке `data\state` (файлы `mbox_...`). Не удаляйте их. |
| Данные за текущий день неполные или сдвинуты по времени | Проверьте `timezone` в `config\config.toml`. |
| Программа не запускается | Выполните `python -m svodka check` — программа назовёт, что не так в настройках. |
| Написано «не найден лист-образец» / «не найден файл-образец» | Проверьте, что файл `templates\svodka_template.xlsx` на месте. |

## 6. Безопасность

**Что уже сделано в программе:**

- По умолчанию принимаются файлы только от отправителей из списка `allowed_senders`. Если отключить проверку (`restrict_senders = false`), делайте это только для закрытого почтового ящика, и не сочетайте с `reply_to_sender = true`: тогда готовая сводка уйдёт любому, кто прислал файл.
- Имена вложений очищаются — файл не может попасть в чужую папку. Принимаются только `.xlsb`, `.xlsm`, `.xlsx`.
- Файлы проверяются по размеру и на «раздутое» содержимое; подозрительные уходят в `data\errors`.
- Текст из присланных файлов не может превратиться в формулу в готовой сводке.
- Почта отправляется по защищённому соединению.
- Программа не открывает сетевых портов и не принимает подключений извне.
- Все настройки проверяются при запуске; опечатка в названии параметра не пропускается молча.

**Что нужно сделать вам:**

- Не копируйте `config\config.toml` в общие папки, почту и репозитории: в нём адреса и настройки почты.
- Раз в несколько месяцев меняйте пароль от почты и обновляйте список `allowed_senders`.

## 7. Обновление программы

1. Остановите программу (`Ctrl+C`).
2. Замените папки `svodka`, `templates` и файл `requirements.txt` на новые версии.
3. Выполните `pip install -r requirements.txt` и снова запустите программу.

Файл настроек `config\config.toml` и рабочие папки при этом не затрагиваются.

## 8. Что где лежит

```
Svodki_proj/
├── config/
│   ├── config.example.toml   образец настроек
│   ├── config.toml           ваши настройки (создаёте вы)
│   ├── manual_values.example.toml  образец БП и коэффициентов
│   └── manual_values.toml    БП и коэффициенты, вписываются руками (создаёте вы)

│   ├── inbox/                сюда кладут файлы ПОНМ
│   ├── results/              готовые сводки
│   ├── errors/               файлы, которые не удалось принять
│   └── state/                служебные записи программы (не трогать)
├── logs/svodka.log           журнал работы
├── templates/                образец сводки (не менять)
├── svodka/                   сама программа
│   ├── __main__.py           команды запуска (check, watch, once, build)
│   ├── config.py             чтение и проверка настроек
│   ├── watcher.py            слежение за папкой, запуск сборки и отправки
│   ├── builder.py            сборка сводки из файла ПОНМ
│   ├── mail_in.py            приём файлов из почты
│   ├── mail_out.py           отправка готовой сводки письмом
│   ├── pdf.py                получение PDF из сводки
│   └── safeio.py             проверки безопасности файлов
├── tests/                    автоматические проверки
├── tools/diagnose_mbox.py    проверка почтового ящика, если вложения не находятся
└── requirements.txt          список необходимых библиотек
```
